## 日常构建与本地预览

Windows 最简单的方式：在项目根目录双击 **`启动本地预览.cmd`**。

它会自动找到当前用户的 Codex Python 运行环境（没有时尝试 Windows `py -3`），构建最新文件并打开默认浏览器，无需手动输入 Python 路径。默认使用 8000 端口，被占用时自动选择空闲端口；不会关闭已经运行的服务。预览期间保留启动窗口，关闭窗口或按 Ctrl+C 停止。源码或模型修改后，关闭旧窗口，再双击启动即可重新构建。

命令行方式需要 Python 3.10+，仅使用标准库。在仓库根目录运行（Windows 有 Python Launcher 时将 `python3` 换成 `py -3`）：

```sh
python3 web/build.py --serve 8080
```

打开 http://127.0.0.1:8080/。预览服务仅监听本机，关闭缓存，按 Ctrl+C 停止。不能直接双击 HTML，网页使用根路径资源。

修改 `web/app.js`、`web/appearance.js`、`web/style.css` 等源码，或从 Blender 重新导出 `Blender工程/网页模型/nokia3310_interactive_v2.glb` 后，重新运行构建并刷新浏览器即可，无需更新旧发布版的哈希。棚拍、材质变化时也运行 `Blender工程/脚本/导出网页棚拍配置.py` 更新 `web/assets/studio.json`。若预览服务仍在运行，可在另一个终端单独构建：

```sh
python3 web/build.py
```

这是一次性构建，不会监听文件变化；构建不会修改 Blender 工程、源 GLB、Git 分支或 VPS。

可指定另一个待预览的模型：

```sh
python3 web/build.py --model /path/to/new-model.glb --serve 8080
```

构建结果位于 `web/dist/`。`build-manifest.json` 记录这次实际生成的 27 份运行资源的大小和 SHA-256，方便与部署文件核对；它不代表已经发布，也不对自身求哈希。源码输出统一使用 LF，避免 Windows Git 换行转换造成复现差异。GLB 和依赖文件按原始二进制字节复制。

## 展示与使用

进入页面后缓慢自动旋转；可以拖动、缩放，也可点“暂停旋转”。点“开始使用”后约 420 ms 转到正面，锁定旋转与缩放；“回到展示”恢复刚才的观察姿态。系统开启减少动态效果时不自动旋转，过渡缩短。

使用时点击或按住实体键帽。摇杆上、下两端分别对应 `up`、`down`；中间窄区无效，跨区滑动取消。方向键按住 400 ms 后每 120 ms 重复一次，松开不追加一次点击。数字和功能键可保持压下，但不自动重复。

进入使用后画布自动获得焦点，也可用 Tab 回到手机操作区。键盘支持 `0–9`、`*`、`#`、`↑`、`↓`、`Enter → Menu`、`Backspace → C`。失焦、隐藏、离开键帽、多点触摸和模式切换都会取消输入。待机按数字开始输入，Menu 打开菜单，上下选择、Menu 确认、C 返回；数字页 C 逐位删除，空白后 C 返回待机。

使用模式按高度 96%／宽度 88% 的上限自动适配完整手机，缩减页脚留白；窗口变化时重新适配，返回展示恢复原观察缩放。LCD 仍为 84×64。

模块分工：`viewer.js` 管理三维资源和唯一调度；`view-modes.js` 管理模式及相机；`input.js` 输出与三维无关的事件；`interaction.js` 负责拾取与物理反馈；`phone-state.js` 管理数字、菜单和设置；`lcd.js` 管理显示基座及唯一纹理；`app.js` 连接模块。

LCD 使用 84×64 方形像素与内置点阵字模，隐藏旧静态文字。数字最长 32 位，选项可清空全部或回主菜单。设置中的主题／声音与外部控件同步。内容不变时不重画，待机时钟按分钟更新，隐藏时停止计时；草稿与菜单为页面内会话状态。

日历：主菜单选 `CALENDAR`。上下或 4／6 换日，2／8 换周，*／# 换月，0 回今天；Menu 查看日期详情，C 逐层返回。日期状态与点阵绘制分别在 `apps/calendar.js`、`apps/calendar-screen.js`，共用现有 LCD，无新增纹理、计时器或网络请求。选中日期仅在当前页面会话保留，不含日程编辑和同步。详见[日历模块与验收](../docs/阶段B2-日历.md)。

贪吃蛇：`Menu → GAMES → SNAKE`，上下选难度，Menu 开始。**2 上、4 左、6 右、8 下**，点击模型或使用电脑数字键均可。Menu 暂停／继续；C 游戏中先暂停，暂停后返回；5 在暂停或结束时回准备页。游戏转向在按下时立即响应，不在松开时重复；摇杆和键盘箭头不用于游戏转向。失焦、隐藏及切回展示自动暂停，回到页面后需 Menu 继续。

规则、绘制、计时与存储分别在 `apps/snake.js`、`apps/snake-screen.js`、`game-clock.js`、`storage.js`。游戏复用一张 LCD 纹理与现有渲染器，暂停后停止游戏计时。主题、声音、难度和按难度区分的最高分存在本机 `nokia3310.preferences.v1`，普通移动不写存储；不可用时保留本次会话。无账户、联网同步或服务器游戏进程。

## 材质主题与棚拍

左上角提供“经典实体 / 玻璃棚拍”滑动开关，支持点击、拖动、Space/Enter 和左右方向键。默认实体主题无透射和自发光；玻璃主题使用 Blender 的 AgX、IOR、薄膜参数及五盏灯的环境图近似。两个主题共用模型、相机与按压进度；主题与展示／使用模式互相独立。

`appearance.js` 集中处理颜色与光照，`theme-switch.js` 处理开关交互。环境图仅生成一次，静止时停止渲染；DPR 上限 1.5，透射目标比例 0.65。WebGL 与 Cycles 的光线路径不同，网页专门校准了有效折射厚度；不能将当前实现描述为两种渲染器逐像素一致。

按键行程倍率在 `interaction.js` 的 `PRESS_TRAVEL_SCALE`（当前 1.35），摇杆使用较小中心位移加两端倾斜；键帽的局部明暗在 `appearance.js` 的 `setKeyFeedback()`；短音参数在 `key-sound.js`。声音默认开启，可用主题开关右侧的按钮静音，偏好保存在本机。有效松开和首次方向重复各响一次，展示旋转与取消不发声。无需下载音频素材，声音合成失败时不影响按压。

## 外部依赖仍严格锁定

`dependencies.lock.json` 只负责 Three.js 依赖，不再锁死项目源码或模型。当前版本为 `0.180.0`：

- 首次构建从 npm 官方 registry 下载 tarball，校验 SHA-512，以及清单中各文件的 SHA-256。
- 只读取允许列表中的六份运行时 JS 和 MIT 许可证，不运行安装脚本，不解压任意归档路径。
- 验证通过的 tarball 缓存在 `web/.cache/`，后续可离线构建；每次使用缓存仍重新校验。
- 校验失败就停止，不自动升级、不绕过校验；输入校验失败时保留原有 `dist` 内容。

也可显式提供离线包：

```sh
python3 web/build.py --tarball /path/to/three-0.180.0.tgz
```

`dist/`、`.cache/` 和 Python 缓存均不提交 Git。浏览器运行时依赖由本地预览服务或网站自身提供，不依赖第三方 CDN。

## 核对 2026-10-03 的历史发布版

`release-snapshots/20261003-black.json` 独立保留当时全部 12 份运行资源的哈希及源提交 `b60447d580e5b99ad4011c843019405182f5f1e3`。它是历史记录，日常开发不要重写：

```sh
python3 web/build.py --verify-snapshot web/release-snapshots/20261003-black.json
```

该选项核对当前源码、模型和依赖能否生成历史版的相同运行资源；有实质改动时应失败。它不会自动回退或覆盖源码。需要重新构建旧版时，在另外的检出目录使用保留的 `deploy/black-viewer-20261003` 分支即可；不要为通过历史校验而改写快照。新版额外生成的 `build-manifest.json` 不在历史运行资源清单内。

## 修改与发布流程

最近一次已完成的发布为 **2026-10-04 / `20261004-snake-1`**：[部署、验证与回退记录](../docs/发布记录-20261004-贪吃蛇.md)，[文件哈希与公网检查](release-snapshots/20261004-snake.json)。源码 `5b32ccc`，包括日历和贪吃蛇。27 份公网资源哈希匹配，本机网络导致正式站点浏览器交互复验未完成；后续修改需独立构建和发布。

1. 从同步后的 `main` 建立功能分支，修改源码或模型。
2. 本地构建，检查显示效果、按键与目标设备表现。
3. 提交并推送代码，确认后再合并。
4. 明确要发布时，将已验证的 `web/dist/` 内容复制到新的服务器发布目录，再切换站点目录，保留上一版以便回退。

构建脚本不含 SSH、上传、自动部署或服务器配置修改。Git 推送与网站发布是两个独立操作。网页必须部署在域名根目录；不要把 Blender 工程、源模型目录或整个 Git 仓库作为公开网站根目录。

Cloudflare 会缓存静态资源。当前发布版本 `20261004-snake-1` 已用于 HTML 的 CSS/JS 链接、应用模块导入、GLB 和棚拍 JSON 地址。后续发布应同步更新 HTML 与所有业务模块导入中的版本参数，包括 `apps/` 内的导入，避免新页面混用旧脚本或旧模型；固定版本的 Three.js 不变。发布验证应核对这些带版本参数的实际请求。
